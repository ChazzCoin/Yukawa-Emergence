=== (1) FOOTNOTE for Thm single proof (after "generated by Tr He, ... Tr(He Hnu)", tex line ~280) ===
Status: the orbit-separation step is NOT in #20 as a clean citation (only Mendes-Radeschi 2012.07914 via summarizer; Schwarz/Procesi-Schwarz not opened). I do not need it: for this case it has a 6-line elementary proof, so I recommend proving it in the footnote and citing the general theorem only as context. What is needed, exactly: (a) compact group, here U(2) acting on the real vector space Herm(2)+Herm(2) by simultaneous conjugation; (b) real polynomial invariants separate orbits; (c) hence any U(2)-invariant function is a function of the invariants. Proof sketch that holds for any compact G (own argument, not a citation): two distinct orbits are disjoint compact sets, so an averaged Urysohn function separates them; Stone-Weierstrass gives a polynomial uniformly close on their union; Haar-averaging it keeps it a polynomial of the same degree and makes it invariant; so some invariant polynomial takes different values on the two orbits. For continuous F this gives F = f(p_1..p_5) (F is constant on fibres of the invariant map, which is proper because Tr He^2 + Tr Hnu^2 is among the p_i). For SMOOTH F, smooth f needs Schwarz 1975 (Topology 14, 63-68; quoted from memory, NOT opened, flag it). For our case the elementary route avoids both: in Bloch form X = c_X 1 + (1/2) delta_X n_X . sigma, U(2) acts through SO(3) on the pair of vectors (n_e, n_nu); the pair is fixed up to SO(3) by its Gram data (|a|,|b|,a.b) (two vectors span at most a plane; a reflection in that plane fixes both, so O(3) equivalence upgrades to SO(3)).
LaTeX:
\footnote{Here a functional is called relational if it is a function of $(\He|_E,\Hnu|_E)$ invariant under simultaneous conjugation by $\mathrm U(2)$. The step from the five polynomial generators to \emph{all} such functionals uses that polynomial invariants of a compact group separate its orbits: if two pairs lie in different $\mathrm U(2)$--orbits, some invariant polynomial takes different values on them (approximate an invariant bump separating the two compact orbits by a polynomial, then average over Haar measure). Hence every continuous invariant function is a function of the five traces. (For smooth $\mathcal F$, smoothness of that function is Schwarz\,\cite{schwarz1975}.) Concretely, in the Bloch form below $\mathrm U(2)$ acts through $\mathrm{SO}(3)$ on the pair of vectors $(\hat n_e,\hat n_\nu)$, and such a pair is determined up to $\mathrm{SO}(3)$ by $\lvert\hat n_e\rvert,\lvert\hat n_\nu\rvert,\hat n_e\!\cdot\!\hat n_\nu$.}
Bib (flag: from memory): G. W. Schwarz, Smooth functions invariant under the action of a compact Lie group, Topology 14 (1975) 63-68. If you drop the smooth clause no citation is needed.
Side fact for Cor aligned (no smoothness of G needed): F(theta) = f(cos 2(theta+psi0)) is even about every aligned point, so any F differentiable in theta has dF/dtheta = 0 there. The proof of Cor aligned can say that instead of "smooth G".

=== (2) CONVERSION det[Phi,Hnu] = 2iJ Delta(n) Delta(m^2)  <->  Jarlskog Eq.7  <->  King Eq.74 ===
Notation: Delta(x) := (x2-x1)(x3-x2)(x3-x1) = prod_{i<j}(x_j-x_i), eigenvalues in the stated label order. Our Vandermonde (n_mu-n_e)(n_tau-n_mu)(n_tau-n_e) = Delta(n) with labels (e,mu,tau); (m2^2-m1^2)(m3^2-m2^2)(m3^2-m1^2) = Delta(m^2). Jarlskog F = (mt-mc)(mt-mu)(mc-mu)/mt^3 = Delta(m)/mt^3 with u<c<t as 1,2,3: (mc-mu)(mt-mu)(mt-mc) = same product, so F = Delta/mt^3. The /mt^3 is a mass normalisation (Eq.8 as read in R2-novelty-sources.md), absent for unnormalised matrices; so detC = -2 J Delta(M)Delta(M2) unnormalised. Both sides are invariant under relabelling (an odd permutation flips Delta and flips J: Delta(n)Delta(m^2) J is label-independent).
Chain (A = algebra, G = given by the sources):
 G. Jarlskog Eq.5: [M,M2] = iC, C Hermitian, so C = -i[M,M2]. Eq.14: C^ = -i[D, V D2 V^dag] in the eigenbasis of M, D = diag(eigs of M), M2 = V D2 V^dag.
 Map: M -> Phi (diagonal, D = diag(n_e,n_mu,n_tau) in the flavour basis), M2 -> Hnu = U diag(m^2) U^dag, V -> U (PMNS). Same commutator order [Phi,Hnu]. J = Im(V11 V22 V12* V21*) = Im(U_e1 U_mu2 U_e2* U_mu1*): same as ours (Jarlskog defines Im(V_ij V_kl V*_il V*_kj) = J sum eps_ikm eps_jln; with i=j=1,k=l=2 this is our J).
 A. [Phi,Hnu] = iC, so det[Phi,Hnu] = det(iC) = i^3 det C = -i det C (3x3: det(cA) = c^3 det A).
 A. Direct evaluation (I derived it, did not rely on Eq.7): in Phi eigenbasis K := Hnu = V D2 V^dag, C_ab = -i (d_a-d_b) K_ab, zero diagonal, Hermitian. det of a 3x3 Hermitian with zero diagonal = 2 Re(C12 C23 C31). C12 C23 C31 = (-i)^3 (d1-d2)(d2-d3)(d3-d1) K12 K23 K31 = i * Delta(d) * K12 K23 K31 [since (d1-d2)(d2-d3)(d3-d1) = Delta(d), two sign flips]. Re(i z) = -Im z, so det C = -2 Delta(d) Im(K12 K23 K31).
 A. Im(K12 K23 K31) = J Delta(m2): K12K23K31 = sum_{ijk} m_i m_j m_k V1i V*2i V2j V*3j V3k V*1k. Only the totally antisymmetric part survives in the imaginary part; fix the sign by the coefficient of m1^2 m2. Delta(m) expands to m2m3^2 - m2^2m3 - m1m3^2 + m1m2^2 + m1^2m3 - m1^2m2, so that coefficient is -1. The three index triples (1,1,2),(1,2,1),(2,1,1) give -J|V21|^2, -J|V11|^2, -J|V31|^2 (each uses Im(V_ai V_bj V*_aj V*_bi) = J eps_abc eps_ijd; values eps_132 eps_123 = -1, eps_231 eps_213 = -1, eps_123 eps_213 = -1). Sum = -J (column-1 norm) = -J. Coefficient of m1^2 m2 in J*Delta(m) is -J. Match, so Im(K12K23K31) = +J Delta(m). Only one coefficient checked; antisymmetry fixes the rest.
 Result: det C = -2 J Delta(n) Delta(m^2)  (= Jarlskog Eq.7 with F F2 -> Delta Delta, reproduced independently). Then det[Phi,Hnu] = -i * (-2 J Delta Delta) = +2i J Delta(n) Delta(m^2). Matches Prop. jarlskog exactly. Sign convention: commutator order [Phi,Hnu] (swap -> sign flips since det(-X) = -det X for 3x3); Delta in ascending index order as above; J = Im(U_e1 U_mu2 U_e2* U_mu1*) = PDG J (c12 s12 c23 s23 c13^2 s13 sin delta in PDG).  The sentence "overall sign is convention-dependent (commutator order, ordering of differences, sign of J)" is right; the three conventions can be named as above.
King Eq.74 / 79 (read in #20 as verbatim "det = (1/3)Tr(...) = 6i Delta J"): this chain is internally inconsistent as printed. For a traceless 3x3 X (a commutator is traceless), Newton gives det X = (1/3) Tr X^3, so Tr X^3 = 3 det X = 6i Delta J if det X = 2i Delta J. So with the factor from (2): det[A,B] = 2i Delta(a)Delta(b) J and (1/3)Tr... equals det, i.e. the value 6i Delta J is the value of Tr([A,B]^3), not of det or (1/3)Tr. Conversion: Tr[A,B]^3 = 3 det[A,B] = 6i J Delta(a)Delta(b) (King value, A,B = MuMu^dag, MdMd^dag, his Delta = six mass-squared differences = Delta(a)Delta(b) ascending). Equivalently King "I_1" as printed is 3x too big if I_1 = det. Either his printed (1/3) is misplaced or his normalisation of I_1 differs; I cannot decide which from the transcription, and have not seen the page. Safest paper wording: cite King for the Tr X^3 form with value 6iJ Delta and Jarlskog for det; do not equate the two. Commutator order in King Eq.79 is [Hnu,He] (opposite to Jarlskog/ours), so Tr flips sign: Tr[He,Hnu]^3 = -6iJ Delta^l in his J convention (sign of his J unchecked).
Calculator check (cheap, 1 line): Tr([Phi,Hnu]^3) / det[Phi,Hnu] = 3 to 1e-12 and det/(2i J Delta Delta) = 1 (lab ef716dd already does the second). Refuter: ratio != 3 would mean [Phi,Hnu] is not traceless-3x3 (impossible), so this is a sanity gate, not a test.

LaTeX for Prop. jarlskog remark (optional):
\noindent\emph{Normalisation.} With $[\hat\Phi,\Hnu]=iC$, $C$ Hermitian, $\det[\hat\Phi,\Hnu]=i^3\det C=-i\det C$, and Jarlskog\,\cite{jarlskog1985} (Eq.\,7, unnormalised masses) gives $\det C=-2J\,\Delta(n)\Delta(m^2)$ with $\Delta(x)=(x_2-x_1)(x_3-x_2)(x_3-x_1)$, hence the stated $2iJ\,\Delta(n)\Delta(m^2)$. For traceless $3\times3$ $X$, $\det X=\tfrac13\operatorname{Tr}X^3$, so $\operatorname{Tr}[\hat\Phi,\Hnu]^3=6iJ\,\Delta(n)\Delta(m^2)$, the form quoted by King\,\cite{king2017}.
